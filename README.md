# RustCollider
### Simples calculadora em C# VS -  para o jogo Rust
A mesma calcula a quantidade de dano necessarios para destruir determinado item com determinada arma e munição - 
Basta escolher a Arma a munição que sera usada e o item que sera o alvo.
os valores foram retirados do propio Wiki da pagina do Rust, sendo valores reais e atualizados -
